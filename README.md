# 가계부 웹 프로그램

간단하고 직관적인 가계부 웹 애플리케이션입니다.  
수입과 지출 내역을 손쉽게 기록하고, 월별/카테고리별 통계를 시각화하여 가계 현황을 한눈에 확인할 수 있습니다.

## 주요 기능

- 수입/지출 내역 등록, 수정, 삭제
- 월별/카테고리별 통계 차트 제공
- 데이터 검색 및 필터링
- 사용자 로그인/로그아웃 기능 (선택적으로 추가)

## 기술 스택

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Java, Spring Framework
- **Database**: Microsoft Azure SQL Database
